# Why We Become — Why Intelligent People Enjoy Being Alone

Package: one 1920×1080 episode (~20:31 incl. end card) + three 1080×1920 Shorts, built on the verified motion-first v2 renderer (Python + OpenCV + Pillow + NumPy, FFmpeg). Narration: supplied Google AI Studio (Elio) recording, unchanged apart from the standard vocal chain.

- `transcript.txt` / `transcript_timed.txt` — script (transcribed from the narration)
- `voiceover.json` — word timings (provisional until the Deepgram nova-3 runner pass)
- `plans/` — beat plans, prompt bundles, asset reuse map, production status
- `seo.md`, `shorts_scripts.md`

Renders run only on GitHub Actions; releases are versioned and never overwrite earlier ones.
